# Tejaswi Rane — Resume Website

A static HTML/CSS resume website prepared for GitHub and Vercel deployment.

## Files
- `index.html` — all resume text is present in the initial HTML source.
- `styles.css` — responsive visual styling.

## Before publishing
1. Review every education and project detail for accuracy.
2. Confirm the internship duration and project descriptions are correct.
3. Do not add your phone number or full address (per assignment instructions).

## Deploy with Vercel
1. Upload these files to a GitHub repository.
2. Sign in to https://vercel.com/ using GitHub.
3. Choose **Add New → Project**, import the repository, and deploy.
4. Since this is a static HTML site, no build command is required. If asked, leave the build command blank and use `./` as the output directory (or use the default static settings).

Open the deployed website and use `Ctrl+U`, then search for `Tejaswi Rane`, `Education`, and `ApnaMandi`.
